## 使用方式

可先選「台灣條件適用、免費方案、開發者、本輪更新」快捷入口，再搜尋產品或資格關鍵字，依紀錄類別、優先層級（S–D）、地區、費用、設定時間、免費額度分類與證據篩選。關鍵字只比對紀錄自己主張、卡片看得到的內容（標題、摘要、資格文字、缺口、費用與額度說明、期限欄位），不比對來源證據、排程時間或內部欄位；要確認「台灣是否可用」請用「台灣資格」篩選，不要只看關鍵字結果。免費額度分類（官方宣稱不限量／暫時不限量／未公布固定上限／有明確限制／尚未核實）直接讀 `quota_classification`；「無限／暫時不限量」專區也由同一欄位判定，不看個別紀錄手動標記的 views。免費專區排除已截止、疑似過期、宣布終止及重複收錄的紀錄，且由 schema 管制的設定費與每月費用判定：兩者皆為 0 一律列入；每月費用未知者只在明確標記 free 時列入；已知每月費用大於 0 的試用（例如七日試用後 US$29.99／月）不列入。設定費零不代表後續免費；歷史仍可從全部紀錄搜尋。預設按綜合優先度排序，可改選「截止日由近到遠」把 60 天內會截止的紀錄排到最前面（沒有截止日者排在後面、維持優先度順序）；卡片底部同時顯示最近的截止點與剩餘天數，少於 7 天轉為警示色，當天截止寫「今天」。每次顯示 24 筆；S 級仍需符合個人資格。本輪更新僅涵蓋批次紀錄明列的複核與新增案例。點開「資格、限制與來源」查看完整摘要、來源查閱時間、核實範圍與下次複核安排。

## 解讀原則

- 官方支持標籤只適用來源支持的特定主張，不表示所有欄位已核實。社群自述、索引摘要與待覆核線索分開。
- Taiwan Yes 是條件式地區資格判斷，仍需滿足列出的帳戶、學籍、企業、付款或居住條件，不保證讀者本人合格。
- 未公布固定上限不等於無限；模型、背景代理、API、共用額度及時日週月限制不可互換。
- 設定費與續費分開。未知數字為 null，不是 0。免費效益成本比分母為零標不適用；沒有可靠情境時不估造節省金額。
- VPN 換 IP 不代表具有地區優惠資格。不建議偽造身分、地址、帳號轉讓或繞過限制。
- 促銷狀態、服務條款資格與法律/監管結論分開呈現；沒有查到適用官方法律來源時，法律狀態標為未核實。符合條款不等於法律意見。
- 促銷可能過期或撤銷，使用前應重查來源。本網站不登入帳戶、不代申請、不購買或啟動外部工作。

## 優先度評分

2026-10-24 起每筆紀錄附 `priority_tier`、`priority_score`、`priority_note`，僅由既有欄位衍生計算，不是新的外部查核，也不是可領取的保證。

- 評分＝可靠度×1.2＋價值＋台灣可用度×1.5＋省力×0.8。
- 可靠度＝證據等級（官方 3／社群回報 1.5／未驗證 0.5）×2＋狀態（active 3／條件式 1.5／已截止 0）×1.5＋用量分類。
- 價值＝類別（FREE、HIGH-QUOTA、VALUE-DEAL 等；REGION-LOCKED 扣分）＋零設定/續費獎勵＋已知可用效益。
- 台灣可用度：Yes ＋3／No −3；省力：≤15 分鐘 ＋2／≤45 分鐘 ＋1。
- 分層：S＝台灣資格標記 Yes；A＝≥19 分；B＝17–19 分；C＝14–17 分；D＝低於 14 分或已過期/截止。政策與待覆核紀錄不評級，優先度排序時列於最後。
- 資料變更後重算：`python3 tools/prioritize.py`。
- 每輪挑選複核對象：`python3 tools/queue.py`（`--limit`、`--json`、`--cooldown-hours`、`--self-test`）。順序是逾期 → 7 日內到期 → 追查失敗待換路線 → 輪替補位；輪替先比 `next_review_at` 再比 `verified_at`，所以佇列不會推薦一個排程在 20 天後的紀錄，卻跳過排程就在本週的紀錄。`retry` 桶（2026-11-10 新增）收的是「最新一次打開官方頁是失敗」的紀錄：它們的排程往往還在 10 天後，冷卻以「最後一次真的打開官方頁」計算，避免同一輪又重讀同一個 404。
## 維護

維護流程、逐輪研究紀錄、失敗經驗與下輪優先清單都在 [MAINTENANCE.md](MAINTENANCE.md)（單一維護入口，逐輪追加）。幾個不變的規則：

- 保留穩定 ID、來源、各筆查閱時間與政策歷史；資料發布不代表已全面複核，`verified_at` 只反映該筆列明的主張。
- 複核順序交給 `python3 tools/queue.py`（先看排程、再看最久未核），不要每輪重寫臨時腳本；死連結用 `python3 tools/linkcheck.py` 掃。
- 免費／台灣資格／額度專區只讀 schema 管制的欄位；同一事實存在兩個欄位時，篩選讀有管制的那一個。
- 未知是 `null` 不是 0；未公布上限不是無限；官方頁互相衝突時保留兩說，不任選一版。
- 發布前跑 `python3 tests/validate.py`、`node --check app.js`、`node tests/filters.cjs`、`git diff --check`；時間戳先對錶（`TZ=Asia/Taipei date -Iseconds`），不得寫入未來時間。
